# Issue Editing Guidelines

This document provides guidelines for editing validated issues.

## Edit Categories

1. **Minor Edits**: Typo fixes, clarification
2. **Scope Changes**: Adding/removing tasks
3. **Dependency Updates**: Changing issue dependencies
4. **Priority Changes**: Adjusting priority or timeline

## Edit Workflow

1. Author proposes edit
2. Reviewer approves/rejects
3. If approved, update issue
4. Notify stakeholders
