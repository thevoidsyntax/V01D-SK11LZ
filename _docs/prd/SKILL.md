# PRD Templates

## Primary Skill

**Use `/feature-forge` for interactive requirements workshop with EARS format.**

```
/feature-forge  → Interactive PRD workshop
/prd            → These templates as reference
```

## Quick Reference

### User Story Format
```
As a [user type]
I want [goal/action]
so that [benefit/value]
```

### EARS Format
```
The system SHALL [requirement]
When [event], the system SHALL [response]
```

### Acceptance Criteria
```
Given [context]
When [action]
Then [outcome]
```
