## 🚀 Master Skill: /auto-router

`/auto-router` adalah **master skill** yang orchestrates semua skill lain berdasarkan project context:

```
User Input → Intent Detection → Tech Scan → Keyword Analysis → Skills Invoked
     │              │               │              │              │
     └── "API baru" ──► CREATE ──► Fastify ──► auth ──► 25+ skills
```

### How It Works

1. **Intent Detection** - CREATE/DEBUG/ANALYZE/DEPLOY
2. **Tech Stack Scan** - Python/Go/React/Kubernetes
3. **Keyword Analysis** - Auth/database/security patterns
4. **Scoring** - CORE + KEYWORD + TECH + INTENT
5. **Auto-Invoke** - Skills dengan score ≥40 otomatis aktif
