# Skill Mechanics

This document describes the mechanics of how skills are invoked, loaded, and executed.

## Skill Loading

Skills are loaded from `~/.claude/skills/` directories. Each skill directory contains a `SKILL.md` file with YAML frontmatter defining metadata and markdown content for the skill behavior.

## Skill Invocation

Skills can be invoked via:
- Explicit command: `/skill-name`
- Auto-invoke based on conditions
- Integration chain from other skills
